# CHANGELOG — sway-mstack

## [Unreleased]

### Добавлено

- **Unit-тесты** (`tests/unit/`, CTest-метка `unit`): 316 проверок
  статических функций — экранирование имён, JSON-доступоры, сбор
  тайлов, пропорции, снимки, кэш эха, построение команд, IPC-фрейминг и
  POSIX I/O. В Debug-сборке проходят под AddressSanitizer и
  UndefinedBehaviorSanitizer.
- **E2E-тесты** (`tests/e2e/`, 8 сценариев, 61 проверка): приватная
  headless-сессия Sway на каждый сценарий, изолированные
  `XDG_RUNTIME_DIR`/`SWAYSOCK`/`WAYLAND_DISPLAY` и свой `sms.lock`.
  Покрыты геометрия n=1/2/3, смерть мастера, зум, крайние движения,
  ротация, tabbed-стопка, длинные имена и второй выход.
- **CI GitHub Actions**: матрица Release и Debug (ASan/UBSan) на Clang 23
  (в clang 18 из Ubuntu нет C23 `constexpr`), unit- и E2E-тесты в
  headless Sway, проверка `cmake --install`.
- **Документация**: `ARCHITECTURE_ru.md` и `ARCHITECTURE_en.md`
  (модель состояния, конвейер событий, быстрые пути, тесты),
  `CONTRIBUTING.md`, `tests/README.md`.

### Изменено

- `src/main.c` разбит на `src/sms.h` и десять фрагментов
  `src/parts/*.inc` для навигации по коду. Демон остаётся одним
  translation unit: CMake собирает только `src/main.c`, статические
  функции и unit-тесты не меняются. Поток токенов после препроцессора
  и Release-бинарник совпадают с прежним монолитом.
- `demo.gif` удалён из репозитория и истории; демо доступно по внешней
  ссылке из README и не клонируется вместе с проектом. История git
  очищена от демо-медиа: `.git` занимает ~250 КБ вместо ~254 МБ.
- README переписан для пользователей: короткое объяснение задачи,
  отличие от штатного Sway, autotiling, swayr и SwayFX, структура
  исходников после разбиения `main.c`. CI-комментарии переведены на
  английский.
- `.gitignore`: демо-медиа и каталоги `build-*/`.
- CMake: `ctest` для unit-тестов, опция `-DSMS_E2E=ON` для регистрации
  E2E в CTest, установка архитектурной документации в
  `share/doc/sway-mstack`.

## [2.1.0] — 2026-11-07

### Исправлено

- **Закрытие мастера при одном окне в стопке.** Sway оставлял
  контейнер с единственным окном, и следующее окно вставало
  вертикально. Теперь раскладка сразу возвращается к горизонтальной:
  мастер слева, стопка справа.
- **`move right` из стопки на соседний выход.** При трёх и более
  окнах окно действительно переезжает на монитор справа; `move left`
  возвращает его обратно.
- **Потеря быстрого жеста.** Кэш эха мог принять движение пользователя
  за собственное и пропустить ретайл. Теперь эхо ставится только на
  явные команды демона, остальные движения вызывают обычный пересчёт.
- **Метки и память зума при переносе окон.** После переноса окна на
  другой стол или выход старые `_m`/`_s`/`_p` больше не ломают мастер
  и стопку: раскладка восстанавливается на новом месте.
- **Недоделанная структура после `split`/`layout`.** Контрольный
  reconcile запускается после любой структурной команды, а не только
  после `move`.
- **Поворот `move right` на мастере без памяти `_p`.** В мастер
  выходит соседнее окно, снятый мастер остаётся вершиной стопки;
  повторный `move right` возвращает всё как было.

### Изменено

- Исполняемый файл и CMake-проект переименованы: `sway-master-stack` →
  `sway-mstack`. При `cmake --install` создаётся совместимая ссылка
  `sway-master-stack`, поэтому старые конфиги Sway продолжают
  работать.
- `CMakeLists.txt`: версия 2.1.0; вместе с бинарником устанавливаются
  `README.md`, `CHANGELOG.md` и `LICENSE` в `share/doc/sway-mstack`.
- README: убрано упоминание несуществующей переменной `SMS_PCT`,
  настройка остаётся только через аргумент командной строки.

### Производительность

- Эталонный сценарий (5 окон, 20 циклов зума): 201 IPC-команда вместо
  265 (−24%), 86 запросов `get_tree`, RSS ~2 МБ в релизной сборке
  (зависит от сессии). Поведение и геометрия не изменились.

## [2.0.1] — 2026-11-02

Технический релиз: точечные исправления, ничего нового.

### Исправлено

- **Регрессия 2.0.0: движения мастера вверх/вниз** — сырой `move up` на
  мастере не делал ничего, `move down` менял мастера с дном стопки, но
  переворачивал порядок середины при 3+ окнах. Теперь оба жеста — точный
  обмен с краем стопки: вверх — с вершиной, вниз — с дном; порядок
  середины стопки сохраняется, `move right` на новом мастере возвращает
  всё как было (инволюция).
- **Фокус после перехода на пустой стол** — закрывающееся асинхронно окно
  (диалог сохранения файла, трей-аплет) могло вернуть пользователя на
  покинутый стол, а фокус — переключиться на стол, которого пользователь
  не видел: кэш фокуса продолжал указывать на окно прежнего стола
  (события `window::focus` при переходе на пустой стол нет). Гвард
  «пользователь на этом столе» добавлен во все три фокусных пути:
  удержание пустого стола, подсветка нового мастера, быстрый путь смерти.
- **Кэш снимков столов** — свободный слот теперь приоритетнее вытеснения
  LRU-жертвы: раньше живой снимок мог быть вытеснен даже при наличии
  свободного слота.
